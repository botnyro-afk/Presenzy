# 🎮 Prezensy - Discord Rich Presence Customizer



## 📥 Download

**Latest Version: v1.0.0**

### Download Options:

1. **Portable Version** (Recommended)
   - Download `Prezensy` folder
   - Extract and run `Prezensy.exe`
   - No installation required

2. **Requirements**
   - Windows 10/11 (64-bit)
   - .NET 8.0 Runtime ([Download here](https://dotnet.microsoft.com/download/dotnet/8.0))
   - Discord Desktop App

## 🚀 Quick Start

1. Download the `Prezensy` folder
2. Run `Prezensy.exe`
3. The app will appear in your system tray
4. Right-click the tray icon to configure
5. Your Discord status will update automatically!

## ✨ Features

- 🎨 **Custom Discord Rich Presence** - Show what you're working on

- 🌍 **Multi-language Support** - 24+ languages available
- 🔄 **Auto-Update** - Always stay up to date

- 💬 **Witty Messages** - Fun status messages
- ⚙️ **Highly Customizable** - Configure everything to your liking

## 🎯 How to Use

### Basic Usage:
1. Launch Prezensy
2. Open any supported application (VS Code, Chrome, etc.)
3. Your Discord status will automatically update!

### Custom Images:
1. Right-click tray icon → "Custom Asset Settings"
2. Enter your Discord Application ID
3. Add image URLs (Imgur or Discord CDN)
4. Save and enjoy!

### Manage Apps:
1. Right-click tray icon → "Manage Apps"
2. Enable/disable specific applications
3. Customize messages and icons

## 🔧 Configuration

### Settings Location:
```
%APPDATA%\Prezensy\settings.json
```

### Custom Discord Application:
1. Go to [Discord Developer Portal](https://discord.com/developers/applications)
2. Create a new application
3. Upload your custom images in "Rich Presence → Art Assets"
4. Copy your Application ID
5. Enter it in Prezensy settings

## 🔄 Auto-Update System

Prezensy automatically checks for updates:
- **Application Updates**: Every 6 hours (requires restart)
- **App List Updates**: Every 30 minutes (no restart needed)
- **Message Updates**: Every 30 minutes (no restart needed)

You can also manually check: Right-click tray icon → "Check for Updates"

## 🛠️ Troubleshooting

### Discord not showing status?
1. Make sure Discord is running
2. Check Discord Settings → Activity Status → "Display current activity" is enabled
3. Restart both Discord and Prezensy

### .NET Runtime error?
- Download and install [.NET 8.0 Runtime](https://dotnet.microsoft.com/download/dotnet/8.0)

### App not detected?
1. Right-click tray icon → "Manage Apps"
2. Make sure the app is enabled
3. Check if the process name matches
