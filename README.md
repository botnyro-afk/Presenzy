## ✨ Features

- 🔘 **Clickable Buttons** - Add interactive buttons to your presence
- 📋 **Multiple Presences** - Create and manage multiple presence profiles
- 🎨 **Multiple Themes** - Choose from various themes (Dark, Light, Dracula, Nord, etc.)
- ⏱️ **Optional Timer** - Show elapsed time on your presence
- 💾 **Export/Import** - Share your presences with friends
- 🖥️ **System Tray** - Runs quietly in the background
- 🚀 **Auto-start** - Launch with your system
- 🌍 **Cross-platform** - Works on Windows, macOS, and Linux

## 🛠️ Build from Source

```bash
# Clone the repository
git clone https://github.com/botnyro-afk/Presenzy.git
cd Presenzy

# Install dependencies
yarn install

# Run in development
npm run start

# Build for your platform
npm run make
```
